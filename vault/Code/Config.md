# Config

> Made by `tools/vault-code-notes.js`. Don't edit it here: rerun the script.

Pure data tables read by server and client. Tune numbers here.

Back to [[Home]].

- [[Achievements config]]: lifetime goals that pay Gems, claimed at the Commendations board in the lobby
- [[Airdrops config]]: mid-run supply crates (Server/Services/AirdropService, Client/Controllers/AirdropController).
- [[Classes config]]: playable roles, unlocked with Gems and chosen in the lobby.
- [[GameConfig]]: global tunables for match flow, waves, economy, upgrades, player, camera, map.
- [[Radio config]]: the commander's lines (vault: Match Start.md). PURE DATA.
- [[Sounds config]]: every sound in the game (pure data; played by Client/Controllers/SoundController).
- [[Survivors config]]: the people living in the safehouse (vault: Lobby.md). PURE DATA.
- [[Tutorial config]]: the first-time player's training run (vault: Lobby.md). PURE DATA.
- [[Weapons config]]: every gun, grouped into 4 upgrade Levels (vault: Weapons.md, Lobby.md).
- [[Zombies config]]: every enemy type. PURE DATA. Server/ZombieModels builds the blocky model from Look
